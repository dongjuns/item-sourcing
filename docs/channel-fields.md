# 외부 연동 필드 대응과 확인 항목

작성일: 2026-09-30. 갱신일: 2026-10-01. 도매꾹 상품상세정보 4.6과 상품 63749955의 실제 조회를 확인했다. 판매 채널 규격·등록 payload는 미검증이며 현재 구현 범위에서 보류한다.

## 확인 상태의 의미

확인 필요는 규격 미검증, 계정 확인 필요는 승인·권한·사업자 조건 미확인, 내부 설계는 이 저장소의 선택을 뜻한다. 확인 완료로 바꾸려면 공식 문서 URL·버전 또는 확인일·계정 적용 여부·검증 fixture 경로를 기록한다. 비밀 값과 인증 응답 원문은 문서에 기록하지 않는다.

실연동에 필요한 항목이 남아 있으면 해당 기능은 mock으로 개발한다. 소싱처 접근·채널 필수 필드·AI 과금 조건은 서로 독립적으로 해소한다. mock 통과로 외부 규격 확인을 완료 처리하지 않는다.

## 다음 확인 순서

1. 도매꾹 공식 상품 조회 규격·API 이용 권한을 확인하고, 키를 env에서 읽는 조회 어댑터로 상품 1건을 수집한다.
2. 인증정보를 제거한 응답 fixture를 확보하고 표준 Product 매핑을 검증한다.
3. 오너클랜 계정 조건·응답을 같은 절차로 확인한다.
4. AI 공급자·비용 상한·이미지 사용 조건을 정한다.
5. 기존 판매 상품 샘플과 채널 공식 문서로 등록 매핑을 확인한다. 테스트 등록은 사람이 화면에서 실행한다.
