## 기록 원칙

새 문제마다 ID·발생 시각·영향·재현 조건·조치·검증 결과를 남긴다. 해결되지 않은 제한은 완료 보고에도 명시한다. 예외 객체나 외부 요청 전체를 그대로 기록하지 않는다. 키·토큰·서명·비밀번호·인증 인자가 들어 있는 URL·DB 접속 문자열은 로그와 문서에서 제외한다.

사용자 설정이나 실제 계정 조건이 미확정인 항목은 외부 규격 확인 목록에서 관리한다. 확인되지 않은 상태를 버그 해결이나 실연동 성공으로 기록하지 않는다.
