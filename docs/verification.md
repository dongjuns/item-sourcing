금액은 조회 시점의 일반 지역 기본 배송비 기준이며 지역 추가금·할인·다른 상품 묶음배송을 포함하지 않는다. 결제나 주문은 하지 않았다. 가격·재고 변경 시 재수집해야 한다. 본문 HTML과 원본 응답은 보존했고 텍스트 추출은 이미지 OCR이 아니다.

실제 조회는 scripts.verify_collection과 scripts.verify_workflow를 명시적으로 실행했다. 자동 테스트와 분리했으며 후자는 수집 API·작업 결과·로컬 자산·금액 API를 검증한다. 전체 원본과 이미지·결과 JSON은 Git 제외 경로에 두고 테스트에는 비밀·공급자 계정 정보를 제외한 수집 관련 필드만 발췌했다.

## 자동 검증

- 백엔드: 실제 응답 정규화 스냅샷, URL 검사, 오류 격리·키 제거, 본문 텍스트 추출, 이미지 저장, 수량 1·2개 및 할인 경계, 수량 제약, 미확인 배송비·가격, 연습 생성, HTML 정제, 편집·확정·재확정·버전 충돌, 예산 예약·불명확 과금, 재시작 복구를 검증한다. OpenAI의 설명 텍스트 전달·구조화 출력·참조 이미지 업로드·썸네일 3장 저장도 fake 응답으로 검증한다. 키 미설정·가격 모델 불일치·전체 비용 초과 시 작업과 호출을 시작하지 않는지 확인한다.
- DB: 새 SQLite DB와 기존 원본이 있는 초기 DB에서 마이그레이션을 검증한다. PostgreSQL은 DDL 생성과 썸네일 FK 포함 여부만 확인하며 서버 실실행 검증으로 간주하지 않는다.
- 프론트: OpenAPI 타입 생성, TypeScript·ESLint·Prettier 검사, 금액·상태 표시 테스트, 프로덕션 빌드를 검증한다.
- 언어 harness 테스트 8개·비밀 검사 테스트 3개와 저장소 소스·문서·비밀 검사를 수행한다. 실제 설정 값은 특정 파일의 테스트 예시 예외보다 먼저 검사한다.
- 테스트에서 실제 네트워크 호출을 차단한다. 생성·확정 흐름의 AI는 명시적인 mock이며 유료 AI 품질 검증이 아니다.

실행 명령은 make lint, make test, frontend의 npm run build다. 미검증 항목은 아래에 남기며 통과한 검사만 PR 설명에 기록한다.

## 실행 중인 서버 확인

2026-10-01 API 8001과 프론트 5174를 다시 기동하고, 프론트 프록시를 통해 HTTP 확인 16건을 통과했다. 비로그인·잘못된 비밀번호의 401, 정상 인증·설정·상품 조회, 실제 원본 사진 3장의 PNG 응답, 수량 1개·2개의 배송비 포함 금액 37,750원·72,750원, 수량 0 거부, 미지원 URL 거부, 연습 생성 계획과 콘텐츠 조회를 확인했다.

기존 수집 상품을 조회했으며 도매꾹 재수집·AI 생성·콘텐츠 수정·판매 채널 등록은 실행하지 않았다. 결과는 Git 제외 경로 assets/verification/runtime-result.json에 저장했다. 이는 실행 서버의 HTTP 검증이며 화면 버튼 클릭 검증과 구분한다. API는 검증용 임시 인증과 AI_MODE=mock으로 실행하며 기존 .env의 비밀 값은 변경하지 않았다.

비어 있던 개발용 모델 설정은 gpt-4.1-mini·gpt-image-1.5로 준비했다. 공식 규격에서 텍스트 구조화 출력과 이미지 편집·3장 출력 지원을 확인했다. [.env.example](../.env.example)에 모델 이름만 반영하고 실제 키·가격 상한·과금 확인 여부는 임의로 채우지 않았다. 실제 계정 접근과 유료 결과는 아직 미검증이다. 근거: [텍스트 모델](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [이미지 모델](https://developers.openai.com/api/docs/models/gpt-image-1.5), [이미지 편집 API](https://developers.openai.com/api/reference/resources/images/methods/edit).

## 남은 검증과 구현

이번 작업은 **화면 버튼 검증과 실제 유료 AI 생성**까지로 제한한다. 연결된 Browser가 없어 화면에서 버튼을 누르는 검증은 수행하지 못했다. 실제 OpenAI 계정·가격 근거·검증 비용 상한이 준비되지 않아 유료 생성은 실행하지 않았다. 이 두 검증은 완료로 표시하지 않는다.

PostgreSQL 실실행·Docker·CI·운영 백업은 발주자 요청으로 보류한다. 옵션 가격 해석·수량별비례 배송비·지역 추가금 계산과 이미지 OCR도 후속 작업이다.
